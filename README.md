# Lamp Login Animation (Versi Sederhana)

Program ini meniru konsep video: halaman login dengan tema gelap dan lampu animasi.

## Isi folder
- `index.html` — struktur halaman login.
- `style.css` — tampilan, responsif, dan animasi lampu.
- `script.js` — interaksi lampu dan validasi form sederhana.

## Cara menjalankan
1. Ekstrak file ZIP.
2. Buka folder `lamp_login_sederhana` di VS Code.
3. Buka `index.html` langsung di browser, atau gunakan ekstensi **Live Server** di VS Code.
4. Klik kolom Password untuk menyalakan efek lampu, lalu isi form dan tekan **Masuk**.

Catatan: login ini hanya demo tampilan, bukan autentikasi sungguhan. Username dan password tidak dikirim atau disimpan ke server.
